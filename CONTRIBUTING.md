# Contributing

1. Select a `READY` item from `agent_plan.md` and confirm its dependencies.
2. Claim it in the active-work table and reserve only the paths needed.
3. Create `feature/AMANOR-<id>-<slug>`.
4. Implement the acceptance criteria and tests without unrelated edits.
5. Run the relevant focused checks and the full `npm run check` gate when application code changes.
6. Open a pull request titled `AMANOR-<id> <summary>` with evidence, risks, screenshots where visual, and rollback notes where operational.
7. Obtain one engineering approval and Product Lead acceptance.
8. Merge only with a green pipeline, then update Jira and `agent_plan.md`.

Security, privacy, accessibility, French parity, sources, consent, Sahel Mode, and public-office capacity rules are part of feature completion, not follow-up polish.
